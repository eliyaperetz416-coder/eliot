# Redesign (dark + marble) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every screen of Demigod in the approved design language: dark gold + silver with a light game feel (artboard E5), a marble theme (artboard E6) chosen in Settings, a floating glass 5-tab bar, and far less text.

**Architecture:**
- **Themes.** One source, `src/core/themes.mjs`, holds the two palettes. `main.js` writes them as CSS variables, so every existing component restyles from the tokens. A contrast test guards both palettes.
- **Shared visuals.** The crest (`emblem.js`), the tab bar and the "sheet"/"row" building blocks are restyled once.
- **Screens.** Each screen is then rebuilt to its section in spec 5.3, reusing the existing data functions. Logic modules (`src/core/*`) do not change, except where a task says so.

**Tech Stack:** Plain ES modules, CSS custom properties, inline SVG, `node --test`, Playwright smoke test (`tests/ui.smoke.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-22-redesign-accounts-design.md`, section 5 and the 22.11 updates. Visual reference: the design canvas https://claude.ai/artifact/1D1yhvbitGxmzE3L7du9Ks, artboards **E5-Balanced** (Today, dark), **E6-Marble** (Today, marble) and the row **D** screens (Workouts, Progress, Crew, Profile, Live, Rest done, Sign-in, Goal).

## Global Constraints

- **Branch only.** `claude/mah-kora-ascpov`. No PR or production release until launch day.
- **Dark palette:** bg `#0A0A0B`, surface `#121214`/`#141416`, line `#1F1E1C`, text `#F2EDE3`, dim `#C9C3B8`, mute `#8C867C`, accent (gold) `#C9A24A`.
- **Marble palette:** bg `#EAE4D9` with soft veins (CSS gradients, as in E6), surface `rgba(255,255,255,.55)`, line `#D8D0C2`, text `#1C1A17`, dim `#3E3A34`, mute `#6B645A`, accent (bronze) `#8A5A2B`.
- **Fonts:** Cinzel for tier names and numbers; Heebo for Hebrew, with weights 400/700, plus 800/900 for big headings (self-hosted, OFL).
- **No purple anywhere.** The purple default accent (`#7c5cff`) is gone.
- **Shop colour themes stay:** a bought and equipped theme overrides the accent in both palettes.
- **Every text pair passes WCAG AA (4.5:1)**, including accent ink on every accent, the shop's included.
- **The rule for every screen (spec 5.2):** one big thing on top; no permanent hint sentences; one-line rows; at most one primary button; the same building blocks everywhere; big numbers, quiet text; lots of air.
- **Zip only in special moments:** the workout-finished screen and rank-up. Never on regular screens.
- **"My model" is removed (UI and route).** The `model` field stays in the data format for compatibility.
- **Settings:** "צבע הדגשה לפי הדרגה" (`accentMode`) is replaced by "ערכת צבע" (`theme: 'dark'|'marble'`).
- **Repo rules:** i18n only, he/en parity, no Hebrew in `src/ui`, `npm run stamp` before every commit, `prefers-reduced-motion` / `[data-motion="reduce"]` stops every animation, touch targets ≥ 44 px, no horizontal overflow at 390 px.

## Review Focus

1. **Marble text contrast.** On a light background, dim and mute text, chips and disabled states must stay readable. → contrast unit test over both palettes (Task 1), plus the route sweep run in marble (Task 12).
2. **A shop colour equipped on marble** (Olympian Gold `#ffc43d` on a light background): buttons stay readable. → unit test of `inkFor` over every shop hex × both palettes (Task 1).
3. **The floating tab bar must not cover content:** the last row of a long screen, the rest-timer bar or a sheet's buttons. → smoke check: last element bottom ≤ tab bar top after scrolling to the end, on Workouts and Progress (Task 4).
4. **Old settings** (`accentMode: 'rank'`, schema v2) migrate to `theme: 'dark'` without a crash, and sync carries `theme` instead of `accentMode`. → settings migration unit test (Task 1).
5. **Reduced motion** stops the crest float, the light rays and the glow. → smoke check: `getAnimations().length === 0` on Today with `data-motion="reduce"` (Task 5).
