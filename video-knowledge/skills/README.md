The source: 105 TikTok/Reels videos (100 unique), transcribed with Whisper plus a frame-by-frame look at each one.
Per-video notes: `../videos/ALL-VIDEOS.md`.

Plus `PROMPTS.md`: a library of ready-to-copy prompts from the videos (Hebrew/English).

## Installation
- **Claude Code (per project):** copy the skill folders into `.claude/skills/` at the project root.
- **Claude Code (personal, every project):** copy them into `~/.claude/skills/`.
- **Claude.ai / desktop app:** Settings → Capabilities/Skills → upload a ZIP of each skill folder.

## Notes
- Star counts, prices and fine amounts are as quoted in the videos. Check them before relying on them. The legal skill is **not legal advice**.
- Some videos only hinted at a tool's name ("comment X and I'll send it"). Where the name wasn't shown on screen, it doesn't appear here.
