## מה יש בנושא

- **GSAP**: אנימציות וגלילה
- **Lenis**: גלילה חלקה. מתקינים ב-`npm i lenis` ועוטפים את האפליקציה

- הדרך: מדביקים את שלושת הקישורים ל-Claude Code והוא מתקין
