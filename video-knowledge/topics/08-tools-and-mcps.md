# 8. כלים, MCPs וחלופות קוד פתוח

**סקיל:** [`tool-stack-reference`](../skills/tool-stack-reference/SKILL.md) · **סרטונים:** 009, 018, 020, 021, 028, 031, 032, 035, 060, 070, 095

## מה יש בנושא

### 5 כלים ש"משחררים" את Claude (095)
| כלי | מה הוא נותן |
|---|---|
| Perplexity | מחקר עומק עם מקורות |
| Firecrawl | "עיניים": סריקת אתרים ומחקר מתחרים |
| PostHog | "חוקר פרטי": איפה משתמשים נתקעים, heatmaps, A/B |
| Playwright | "ידיים": שליטה בדפדפן, טפסים ובדיקות |
| Composio | חיבור לכל האפליקציות במקום אחד |

### יכולות מיוחדות
- **REA (Reverse Engineer Anything)**: מנתח אפליקציה קיימת ומחזיר מה נצפה, מה הוסק ומה לא ידוע, ואז בונים גרסה משלכם (020, 032)
- **Expo Skills**: אפליקציות לאייפון ולאנדרואיד, כולל העלאה לחנויות (035)
- **VoiceMode**: מדברים עם Claude Code בקול. אין עדיין תמיכה בדיבור בעברית (070)
- **צוותי בוטים** עם מחשב וזיכרון לכל בוט (OpenMausBot) (018, 031)
- עוזר "Jarvis" על המחשב: הודעות, יומן, זיהוי תמונות (028)
