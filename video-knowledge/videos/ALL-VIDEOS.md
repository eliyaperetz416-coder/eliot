## 034 · Severe PHP vulnerabilities: RCE without authentication (57s, he)
- PHP runs ~70% of the internet. Two vulnerabilities let attackers run any code on the server (WordPress, online shops, Laravel). The bug is **in PHP itself**, not your code.
- How it works: one request without authentication makes PHP run out of memory → leftovers stay in memory during cleanup → takeover → passwords, keys, the DB.
- The details leaked before the fix. Cloudflare is already seeing attack attempts. AI makes building exploits easier.
- What to do: **update PHP today** (or ask the hosting company). Updating plugins isn't enough. Lovable/Next.js apps aren't affected directly, but check what your landing page runs on.
